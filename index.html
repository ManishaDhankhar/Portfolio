My Work

UnityRent(Website)

A peer-to-peer rental marketplace that lets students safely share and rent academic resources. Built with the MERN stack, AWS S3, JWT authentication, and Material-UI — featuring payment gateway integration with custom escrow logic, role-based access control (RBAC), and Student ID validation for secure, trusted transactions.

Jal Drishti(Web and App)

A geospatial decision support system that automates the evaluation of Rooftop Rainwater Harvesting (RTRWH) and hydrological recharge potential. Built using Sentinel-2 multi-spectral imagery, QGIS, and Python — featuring a U-Net and Mask R-CNN pipeline for high-precision rooftop segmentation (90%+ accuracy), with VR visualization to simulate runoff patterns for urban sustainability planning.

The Roaming Hub (Website)

A distributed property platform combining a Node.js engine with a Python AI microservice, using Mapbox GL JS for interactive geospatial visualization. Features a RAG (Retrieval-Augmented Generation) pipeline with ChromaDB and Gemini 1.5 Flash for hallucination-free AI recommendations, with automated CI/CD deployment via GitHub Actions and Docker for high-availability.
