# Portfolio
# 🌐 Manisha Dhankhar | Portfolio Website

A personal portfolio website showcasing my projects, skills, and experience — built from scratch using HTML & CSS.

🔗 **Live Demo:** [manishadhankhar.github.io/Portfolio](https://manishadhankhar.github.io/Portfolio/)

## ✨ About

This portfolio highlights my journey as a Computer Engineering student and full-stack developer — featuring my projects, technical skills, hackathon achievements, and ways to get in touch. Designed to be clean, responsive, and recruiter-friendly.

## 🚀 Features

- Fully responsive layout (mobile, tablet, desktop)
- Clean, modern UI with smooth navigation
- Sections for About, Skills, Projects, and Contact
- Fast-loading static site, deployed via GitHub Pages

## 📂 Folder Structure

```
Portfolio/
├── index.html
├── style.css
├── images/
│   └── (screenshots & assets)
└── README.md
```

## 🖥️ Run Locally

```bash
git clone https://github.com/ManishaDhankhar/Portfolio.git
cd Portfolio
```

Then just open `index.html` in your browser — no build tools or dependencies required.
